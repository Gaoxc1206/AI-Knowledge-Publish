# Kasha's rule

## 标准定义

Kasha's rule 是分子光物理中的经典经验法则：对于大多数荧光分子，吸收后会先通过超快的振动弛豫和内转换回到最低激发单重态 [[第一激发单重态]]，随后再从该态发射荧光。因此，荧光发射通常主要由最低激发态决定，而与最初激发到哪个更高能级关系较小。它常与 [[荧光]]、[[Stokes shift]] 以及激发态弛豫过程一起讨论。

## 在本知识库中的用法

在这篇荧光分子[[inverse design|反向设计]]框架中，Kasha's rule 主要作为解释 [[λemi]] 与激发态弛豫关系的光物理背景。作者在 [[TD-DFT]] 工作流中由于未做激发态几何优化，使用 S0 到 S1 的 vertical excitation wavelength 近似发射峰，这一做法可视为对 Kasha 发射机制的简化处理，但也意味着对真实发射过程的刻画不完整。

## 关键点

- 标准含义上，Kasha's rule 强调：分子发光通常来自最低激发态，而不是“从哪里激发就从哪里发光”。
- 它解释了为什么荧光设计中常把发射性质视为由单一主导激发态控制，这与 [[荧光分子]] 的性质建模密切相关。
- 在本知识库所述方法里，[[λemi]] 的估计依赖 TD-DFT 的简化流程；由于没有进行激发态构型优化，结果更接近近似而非严格的 Kasha 发射计算。
- 该法则为理解 [[Stokes shift]]、激发态弛豫和发射峰位置提供了基础背景。
- 对于含有复杂激发态动力学、异常发光路径或非经典体系时，Kasha's rule 可能不是完全充分的描述。

## 外部背景

- 经典表述通常包含“快速内转换后从最低激发单重态发射”的内容；具体原始出处与教材表述可再核对经典来源。
- 它常被视为荧光和磷光光物理的基础经验法则，但对某些特殊体系存在偏离或所谓 anti-Kasha 行为，待核对经典来源。
- 在[[计算化学]]中，若要更准确预测发射峰，常需要考虑激发态几何优化与垂直/绝热发射差异，待核对经典来源。
