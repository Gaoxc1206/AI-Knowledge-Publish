# 黑盒 oracle

## 标准定义

黑盒 oracle 是优化问题中用于评价候选解优劣的外部函数或过程。它通常只返回一个分数、标签或可比较的反馈，而不暴露内部机制、解析表达式或梯度信息；因此算法只能通过查询 oracle 来进行 [[黑盒优化]]。这类 oracle 往往对应昂贵的实验、仿真或启发式评分器。

## 在本知识库中的用法

在本知识库对应论文中，black box oracle 指用于评价候选分子的外部评分函数 $O(m)$。论文把[[小分子优化]]写成 $m^* = \arg\max_{m \in M} O(m)$，其中 oracle 可以是实验测量、量子模拟、[[蛋白-配体 docking|对接]]打分或其他昂贵评价函数。整个[[分子优化]]流程围绕有限 oracle 调用预算展开：先生成候选分子，再由 oracle 反馈分数，更新高分分子池，并在停滞时对模型进行微调。

## 关键点

- 标准含义上，black box oracle 只提供查询结果，不提供可解释的内部结构或梯度，因此适合描述 [[分子优化]] 中的目标评价器。
- 在本文中，oracle 是分子性质的最终裁判，用来决定候选 [[SMILES]] 是否值得保留、继续[[mutation|变异]]或作为微调样本。
- 论文强调 oracle 调用预算有限，所以优化重点不是穷举搜索，而是在少量查询下尽快找到高分分子。
- black box oracle 可以对应不同来源的评价信号，如实验性质、模拟结果或启发式打分；这使方法能够面向任意目标函数泛化。
- 它与 [[遗传算法]]、[[拒绝采样]] 和[[提示优化]]共同构成分子搜索闭环：模型生成，oracle 评分，池子更新。

## 外部背景

- 在经典优化与机器学习中，黑盒函数优化指目标函数可查询但不可解析，待核对经典来源。
- ‘oracle’ 在算法语境里常指能够回答特定查询的理想化组件；在这里更接近评分器或判定器，待核对经典来源。
- 与可微目标不同，black box oracle 不提供梯度，因此常与 [[进化算法]]、[[Bayesian Optimization|贝叶斯优化]]、随机搜索等方法配合，待核对经典来源。
- 黑盒 oracle 的质量会直接影响优化上限：如果评分噪声大、偏差强或稀疏，搜索过程会更难收敛，待核对经典来源。
