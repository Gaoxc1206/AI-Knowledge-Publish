# 拥挤距离

## 标准定义

拥挤距离（crowding distance）是一类用于[[Multi-objective Evolutionary Algorithm|多目标进化算法]]中的密度估计指标，通常在同一 [[非支配排序]] 层内衡量个体在 [[Pareto Front|Pareto前沿]] 附近的“稀疏程度”。一般来说，某个解周围越稀疏，其拥挤距离越大，越适合被保留，从而帮助维持解集的多样性。它本质上是一个多样性维护准则，不直接表示支配优劣。

## 在本知识库中的用法

在这篇论文中，拥挤距离被扩展为面向[[多模态多目标优化|多峰多目标优化]]的 [[Neighborhood Fuzzy Crowding Distance]]（NFCD）。其做法是同时考虑[[决策空间]]与[[目标空间]]中的邻域拥挤信息，并通过 [[模糊集合理论]] 融合，用于多样性档案 DArc 的选择与截断。该用法的目标不是只保持目标空间分布，而是尽量保留不同的 [[Pareto最优解集|Pareto optimal solution set]]，尤其是 local PS，同时减少孤立个体对搜索资源的浪费。

## 关键点

- 标准拥挤距离主要用于衡量个体在解集中的局部稀疏性，常与 [[非支配排序]] 结合，用来在同一层内优先保留更分散的解。
- 在本知识库对应论文中，拥挤距离被改造成 NFCD，将 [[决策空间]] 与 [[目标空间]] 的邻域信息一起考虑，更适合 [[多峰多目标优化]]。
- 论文强调，单纯基于目标空间的拥挤距离不足以区分不同 PS；引入邻域与模糊融合后，可以更好地区分 global PS 与 local PS。
- NFCD 主要服务于多样性档案 DArc 的更新与截断，和收敛档案 CArc 的自适应收敛指标形成互补。
- 与传统拥挤距离相比，NFCD 更关注“局部邻域中的稀疏性”而不是全局平均分布，因此更适合多个 PS 彼此分离的场景。

## 别名

- crowding distance
- CD
- 拥挤度
- 环境距离

## 外部背景

- 经典多目标[[Evolutionary Algorithm|进化算法]]中，拥挤距离常用于保持种群分布均匀性，待核对经典来源。
- [[NSGA-II]] 中的 crowding distance 是最常见的教材级定义之一，通常在同层个体之间按目标维度计算，待核对经典来源。
- 拥挤距离也可在决策空间、目标空间或两者联合空间中定义，具体形式依赖算法设计，待核对经典来源。
- 在多峰/多模态问题中，拥挤距离常被改造为邻域版、分段版或加权版，以增强对多个解簇的识别能力，待核对经典来源。
