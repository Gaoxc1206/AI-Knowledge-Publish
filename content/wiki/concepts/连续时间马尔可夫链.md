# 连续时间马尔可夫链

## 标准定义

连续时间马尔可夫链（CTMC）是定义在离散状态空间上的随机过程，状态随连续时间演化，并满足马尔可夫性：未来只依赖当前状态而与过去无关。它通常由跃迁速率矩阵（或无穷小生成元）刻画，矩阵中的非对角元素表示单位时间内从一个状态跳到另一个状态的速率，对角元素由行和为零确定。CTMC 常用于描述事件在随机时刻发生的跳变过程。

## 在本知识库中的用法

在这篇工作中，连续时间马尔可夫链是 [[Discrete Flow Matching]] 的底层离散生成动力学：序列被视为离散 token 状态，采样时通过 token 级转移速率/velocity field 推动状态随时间跳变。MOG-[[Discrete Flow Matching|DFM]] 不重新训练这个生成器，而是在 CTMC 采样过程中对候选 token 转移进行多目标重加权，并结合自适应超锥过滤，让轨迹更接近给定权重向量对应的 [[Pareto front]] 折中方向。

## 关键点

- CTMC 适合描述离散状态之间的连续时间跳变，因此比连续嵌入更自然地保留序列 token 结构。
- 其核心参数通常是跃迁速率矩阵/生成元；在离散生成模型里，这对应每个 token 替换的瞬时转移强度。
- 在本知识库所对应的论文中，CTMC 作为 [[Discrete Flow Matching]] 的采样基础，被用于[[生物序列设计|可控生物序列设计]]。
- MOG-DFM 在 CTMC 采样阶段加入多目标引导，而不是修改离散状态空间本身。
- 这种表述使多目标评分、方向一致性与采样动力学能够直接结合，便于生成接近 [[Pareto front]] 的序列。

- CTMC 的经典教材定义通常从生成元矩阵、Kolmogorov 前向/后向方程和等待时间分布出发；待核对经典来源。

- 离散生成模型中的 CTMC 往往采用逐 token 的局部转移，而不是对整个序列做一次性重写；待核对经典来源。
