# 连续时间马尔可夫链

## 标准定义

连续时间马尔可夫链（[[CTMC]]）是一类在连续时间上演化、状态通常离散的随机过程，满足马尔可夫性质：系统未来只依赖当前状态，不依赖更早历史。它通常由[[Transition rate|转移速率]]矩阵或生成元刻画，状态分布随时间变化可写成 [[Kolmogorov前向方程]]；在生成建模里，也常被视为通过随机跳转在离散状态空间中逐步生成样本的基础过程。

## 在本知识库中的用法

在这篇论文里，CTMC 是 [[离散流匹配]] 的底层生成过程，用来描述生物序列 token 在时间轴上的逐步跳转。[[MOG-DFM]] 先对 CTMC 的 token-level [[Transition rate|transition rate]]s 按多目标偏好重加权，再结合角锥过滤选择候选 token，最后用 [[Euler采样]] 实现离散序列生成。这里的 CTMC 主要服务于多目标 Pareto 引导的离散采样，而不是作为独立理论重点展开。

## 关键点

- CTMC 以连续时间刻画离散状态转移，核心对象是转移速率而不是离散步数。
- 标准定义中，CTMC 的时间演化由速率矩阵/生成元决定，并满足 [[Kolmogorov前向方程]]。
- 在本文中，CTMC 被嵌入 [[离散流匹配]] 框架，作为序列 token 逐位跳转的生成轨迹。
- MOG-[[Discrete Flow Matching|DFM]] 通过多目标打分对 CTMC 的转移速率进行重加权，使采样方向更接近 [[Pareto front]]。
- 论文还把 CTMC 与 [[Euler采样]] 结合，在引导后的速率下执行逐步跳转生成。

## 别名

- CTMC
- 连续时间马尔可夫过程
- 连续时间马尔可夫过程（CTMP）

## 外部背景

- 标准教材里，CTMC 常用生成元 Q（或速率矩阵）定义，转移概率可由矩阵指数或前向/后向方程描述。
- CTMC 适合建模“事件在连续时间随机发生”的系统，例如排队系统、化学反应网络和可靠性分析。
- 在机器学习与生成建模中，CTMC 也常被用于离散扩散、随机跳变过程和 token 替换式生成。
- CTMC 与离散时间马尔可夫链的主要区别在于：前者的状态跳变发生在连续时间轴上，而非固定步长。
