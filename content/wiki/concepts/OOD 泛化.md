# OOD 泛化

## 标准定义

OOD 泛化（[[OOD generalization|out-of-distribution generalization]]）指模型在测试时面对与训练分布不同的数据、任务或条件时，仍能保持[[validity|有效性]]能的能力。这里的“分布不同”可以表现为样本统计特征变化、任务组合变化、提示表达变化或约束条件变化。它通常与[[分布偏移]]、[[零样本泛化]]、[[多任务学习]]和组合泛化能力相关。

## 在本知识库中的用法

在这篇论文里，OOD 泛化主要指 [[分子优化基础模型|GeLLM4O-Cs]] 对训练中未见过的属性组合和多目标约束的 [[0-shot 泛化]]能力。论文强调，specialist 模型依赖特定属性组合，通常不适用于 OOD 任务；只有 generalist 模型会被用于 OOD 评估，并且在所有 OOD tasks 上都优于 baselines。

## 关键点

- 标准上，OOD 泛化关注模型能否应对[[分布偏移]]，而不是只在训练集同分布条件下表现良好。
- 在本论文中，OOD 不是普通样本外测试，而是指未见过的属性组合、目标搭配和指令表达下的[[分子优化]]任务。
- 论文中的 OOD 结果主要用来检验 generalist 模型是否真的学到了可迁移的结构修改规律，而非记忆固定任务模板。
- OOD 评估与[[零样本泛化]]密切相关：模型需要在不针对该组合单独训练的情况下完成优化。
- 从实验结论看，多任务[[Instruction Tuning|指令微调]]提升了 OOD 泛化，但也可能因任务间冲突而削弱某些特定组合上的专门化能力。

## 别名

- 分布外泛化
- out-of-distribution generalization
- OOD generalization
- 分布外鲁棒泛化

## 外部背景

- OOD 泛化常见于机器学习鲁棒性评估，用于衡量模型面对训练集之外的条件时是否仍能工作。
- 它与[[组合泛化]]有关：模型需要把已学到的属性、规则或子技能重新组合到新任务上。
- 在指令微调或对话模型中，OOD 泛化也可能体现为对未见 prompt wording、未见任务格式的稳健响应。
