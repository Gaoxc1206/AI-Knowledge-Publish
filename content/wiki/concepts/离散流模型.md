# 离散流模型

## 标准定义

离散流模型是将 [[Flow Matching]] 或流式生成思想推广到有限词表、符号串或其他离散状态空间的一类[[深度生成模型|生成模型]]。它通常通过学习离散 token 之间的转移概率、替换规则或跳跃过程，在基础分布与数据分布之间逐步变换，从而直接建模离散结构的生成，而不是先映射到连续潜变量再解码。

## 在本知识库中的用法

在这篇论文里，离散流模型主要指 [[Rectified Discrete Flows]]（[[ReDi]]）这一类离散生成先验：先用其提供每个位置的 token 级替换概率，再叠加多目标奖励引导与 [[Metropolis-Hastings]] 接受/拒绝步骤，用于肽序列和 peptide [[SMILES]] 的多目标采样。它在这里是 [[AReUReDi]] 的底座，用来保留离散 token 结构并支持局部编辑，而不是[[多目标优化]]本身。

## 关键点

- 标准上，离散流模型面向离散状态空间，学习 token 级转移或重写路径，不依赖连续 latent 表示。
- 本库中它具体承担 ReDi 先验的角色，为局部 [[mutation]] 提供 proposal，再与多目标 reward 结合。
- AReUReDi 通过 [[annealed guidance]]、[[locally balanced proposals|locally balanced proposal]] 和 [[Metropolis-Hastings]]，把离散流采样推向近似 [[Pareto front]] 的区域。
- 相较连续生成方法，离散流更容易保留序列语法、化学 token 结构和局部可解释编辑。
- 论文中的离散流不是单独的优化器，而是[[controllable generation|可控生成]]骨架，配合 [[Tchebycheff scalarization]] 做多目标折中。

## 别名

- 离散流
- 离散 Normalizing Flow
- Discrete Flow
- Rectified Discrete Flow
- ReDi

## 外部背景

- 待核对经典来源：离散流常被视为连续 normalizing flow 在 categorical / jump process 上的推广。
- 待核对经典来源：常见实现会使用逐步 token 替换、离散扩散或马尔可夫转移来近似流式变换。
- Rectified 变体通常强调通过重参数化或修正 coupling，减轻因独立分解带来的误差。
- 离散流适合序列、图和符号数据，但训练与采样常比连续流更依赖特定转移设计。
