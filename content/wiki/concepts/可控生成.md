# 可控生成

## 标准定义

可控生成是指在[[生成模型]]输出过程中，通过条件输入、约束、评分函数或引导策略，使生成结果朝着指定属性、结构或分布目标移动的能力。它强调“生成自由度”与“目标可达性”之间的平衡，常见实现包括[[条件生成]]、解码时引导、基于奖励的重加权与[[约束优化]]。在多目标场景中，可控生成通常不是追求单一最优，而是希望沿着[[Pareto Front|Pareto前沿]]获得可接受的折中解。

## 在本知识库中的用法

在本知识库对应论文中，可控生成特指：在预训练[[Discrete Flow Matching|离散流匹配]]生成器的采样阶段，不重训底座模型，而是通过多目标评分、方向一致性重加权和自适应超锥过滤，把离散生物序列生成轨迹推向更优的多目标折中区域。该用法主要服务于[[肽结合物设计]]与 enhancer DNA 设计：前者同时控制 affinity、hemolysis、solubility、half-life 与 non-fouling，后者同时控制 enhancer class 与 DNA shape。

## 关键点

- 可控生成关注的是“在生成过程中施加控制”，而不是只在训练后做筛选；在这篇工作里控制发生在采样时。
- 论文把可控生成具体化为对[[多目标优化]]的序列生成：希望样本沿着不同权重向量对应的折中方向逼近更好的[[Pareto Front|Pareto前沿]]区域。
- MOG-DFM 的控制对象是离散序列 token 的转移，而不是先把序列映射到连续空间再优化，因此更贴合[[Discrete Flow Matching|离散流匹配]]的生成机制。
- 控制信号来自多个预训练 score functions，并通过 rank-directional scoring 与[[超锥过滤]]共同作用到采样路径。
- 该框架既适用于 peptide binder，也可迁移到 enhancer DNA，说明这里的可控生成是一种跨生物序列类型的通用采样范式。

## 别名

- controlled generation
- controllable generation

- 条件生成
- 引导生成

## 外部背景

- 可控生成常见于文本、图像和[[分子生成]]任务，基本思想是在不完全重建模型的前提下对输出属性进行定向约束。
- 经典实现路径包括条件生成、classifier guidance、reward guidance 和 constrained decoding；不同方法的主要差异在于控制信号是在训练阶段还是采样阶段注入。
- 在[[多目标优化]]语境下，可控生成通常会引入权重向量、偏好向量或目标约束，以在多个冲突目标之间寻找折中解。
- 离散生成任务中的可控生成往往比连续空间更难处理，因为需要直接操控 token 级别离散转移而不是连续扰动。
