# 大语言模型

## 标准定义

大语言模型（LLM）通常指基于 Transformer 的大规模语言建模系统，使用大量文本进行预训练，学习序列中的统计规律与上下文依赖；在下游任务中可通过提示、继续预训练或微调完成分类、生成、问答与[[可控生成|条件生成]]等任务。它既可以作为通用的序列建模器，也可以作为知识载体和生成器，输出概率可在一定程度上反映模型对输入模式的熟悉程度。

## 在本知识库中的用法

在本知识库对应论文中，大语言模型被用来把 [[SMILES]]、分子性质和相似性信息统一表示为文本，并继续训练成面向化学任务的模型（如 Chemlactica-125M、Chemlactica-1.3B、Chemma-2B）。它在这里同时承担三种角色：进行[[分子性质预测]]、按目标性质进行条件生成，以及在黑盒 oracle 反馈下作为[[分子优化]]器的候选生成模块；当优化停滞时，还会对模型做动态 fine-tuning 以适配当前搜索到的高分分子模式。

## 关键点

- 标准定义上，LLM 是对长序列进行自回归建模的通用模型，常用于 [[SMILES]]、自然语言与结构化文本。
- 在该论文中，LLM 被进一步化学化：通过把分子结构、性质、相似分子等信息写成文本，让模型学习结构—性质映射。
- 论文把 LLM 同时用于 [[性质预测]] 和 [[条件生成]]，而不是只做一次性采样生成。
- 在优化阶段，LLM 作为生成器嵌入 [[black-box oracle]] 驱动的搜索流程，与 [[遗传算法]]、[[拒绝采样]]式筛选和 prompt 设计结合。
- 论文还使用动态 [[fine-tuning]]，让模型在分子搜索停滞时继续适配当前高分样本分布。
- 模型输出概率与校准结果被用作分子[[分子性质预测|性质预测]]可靠性的粗略信号，但这一点主要适用于训练语料分布内。

## 别名

- LLM
- 大型语言模型
- Large Language Model

## 外部背景

- 大语言模型通常以 causal language modeling 或 masked language modeling 进行预训练，后者更常见于双向编码器；具体范式取决于模型架构与任务设置。
- 在计算化学中，LLM 常被用于把分子转写为 SMILES 序列后进行生成、补全、属性回归或条件优化，属于序列到序列/序列到性质的统一建模思路。
- 模型规模增大与继续预训练通常会提升下游表现，但在化学任务中仍受数据分布、表示规范化和解码策略影响较大，待核对经典来源。
- 大模型的生成结果常需要结合约束解码、采样策略和后处理过滤，以降低无效分子比例，待核对经典来源。
