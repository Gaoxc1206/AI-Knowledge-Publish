# 非支配排序

## 标准定义

非支配排序（non-dominated sorting）是[[多目标优化]]中的一种分层方法：根据个体之间的[[支配关系]]，把解集按支配层级划分为若干层，第一层通常对应[[Pareto前沿]]上的[[Pareto 最优|非支配解]]，第二层为被第一层支配但彼此之间互不支配的解，依此类推。它常用于[[多目标优化]]和[[Evolutionary Algorithm|进化算法]]中，为选择、保留与精英策略提供排序依据。

## 在本知识库中的用法

在 [[MOMO]] 中，非支配排序作为 Pareto dominance-based evaluation strategy 的核心步骤之一，用于对“父代种群 + 子代种群”合并后的候选分子进行层级划分，并据此选择下一代。这里它不是单独决定所有保留个体的唯一规则，而是与 [[Reference Point Mechanism|reference point]] mechanism 和 dynamic acceptance probability 一起工作，帮助在解码后的分子空间中筛出位于非支配层、且在 [[QED]] / [[PlogP]] / [[DRD2]] / Similarity 等目标上具有不同权衡的候选分子。

## 关键点

- 非支配排序把多目标解集分成多个支配层，第一层对应当前近似的 [[Pareto前沿]]。
- 它的作用不是给每个候选分子算一个加权总分，而是保留多目标问题的 trade-off 结构。
- 在该论文的 MOMO 框架中，非支配排序用于合并父代与子代后进行筛选，是种群更新的一部分。
- 论文中的评价发生在分子空间而非 [[潜在空间|latent space]]：latent vector 负责进化，解码后的分子负责目标计算与非支配层判定。
- 结合[[Reference Point Mechanism|参考点机制]]后，非支配排序有助于在多个目标偏好之间保留更丰富的候选分子。

## 外部背景

- 常见于 NSGA-II 等经典[[Multi-objective Evolutionary Algorithm|多目标进化算法]]中，用于实现精英保留与层级选择。
- 待核对经典来源：非支配排序通常还会与 crowding distance 或其他多样性维护策略配合使用，以避免解集过早集中。
- 待核对经典来源：当目标数增加时，非支配层会变得更难区分，排序的判别力可能下降，这也是多目标高维优化中的常见问题。
