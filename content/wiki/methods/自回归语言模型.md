# 自回归语言模型

## 标准定义

自回归语言模型是一类按序列位置逐 token 建模的生成模型，假设当前 token 仅依赖于前文上下文，并通过最大化下一 token 概率进行训练（也常称为 causal language modeling）。在化学场景中，可以把 [[SMILES]]、性质标签、相似性描述等线性化为文本序列，从而让模型同时支持[[分子性质预测|性质预测]]、[[可控生成|条件生成]]与序列补全。

## 在本知识库中的用法

在本知识库对应论文中，自回归语言模型是核心建模与生成器：作者继续训练 Chemlactica-125M、Chemlactica-1.3B 和 Chemma-2B，使其从包含分子结构、计算/实验性质和相似分子信息的语料中学习分子—性质关系；推理时既用于性质预测与条件生成，也作为群体式[[分子优化]]中的候选生成模块，并在搜索停滞时结合 oracle 反馈做额外 fine-tuning。

## 关键点

- 核心机制是按顺序预测下一个 token，因此天然适合处理线性化后的 [[SMILES]] 与性质文本。
- 在该论文中，自回归训练目标让模型把分子结构、性质和相似性统一到同一文本空间中学习。
- 它不仅能做性质预测，还能在给定目标性质时进行条件生成，并作为 [[prompt optimization]] 的生成后端。
- 在分子优化流程里，模型生成的新候选会经过 [[oracle]] 打分，再用高分样本继续更新模型，形成迭代搜索。
- 论文中的结果表明，模型规模、采样策略与动态 [[fine-tuning]] 会显著影响优化效果与有效[[分子生成]]率。
- 与基于 [[遗传算法]] 或纯规则搜索的方法相比，自回归模型更擅长把大规模语料中学到的模式迁移到[[黑箱优化|黑盒优化]]任务。

## 别名

- 因果语言模型
- causal language model
- AR LM
- 自回归 LM

## 外部背景

- 经典自回归模型通常采用左到右的因果掩码训练，代表性实现包括 GPT 类模型；待核对经典来源。
- 在分子生成中，自回归方法常与采样、[[Beam Search|束搜索]]、约束解码等策略结合，以提高有效性和可控性。
- 相较双向编码器，自回归模型更适合直接生成完整候选，但对长程约束和格式正确性更依赖[[Prompt Engineering|提示设计]]与解码参数。
- 自回归训练通常使用 teacher forcing；待核对经典来源。
