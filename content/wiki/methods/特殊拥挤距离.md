# 特殊拥挤距离

## 标准定义

[[拥挤距离]]（[[拥挤距离|crowding distance]]）是[[Multi-objective Evolutionary Algorithm|多目标进化算法]]中常用的多样性度量，用来估计某个解在局部邻域中的稀疏程度，通常用于[[非支配排序]]后的截断选择。所谓“特殊拥挤距离”通常可理解为在标准拥挤距离基础上的扩展版本，例如引入[[决策空间]]、[[目标空间]]、邻域信息或[[模糊集合]]融合机制，以更适应复杂分布的解集维护。

## 在本知识库中的用法

在该论文中，特殊拥挤距离对应的是 [[Neighborhood Fuzzy Crowding Distance]]（NFCD）。它不只看单一空间，而是把个体在[[决策空间]]与[[目标空间]]中的邻域拥挤程度结合起来，并通过模糊融合得到综合稀疏度，用于 ACEA-NFCD 中的选择与截断。作者将其用于 [[双档案]] 进化框架中的多样性维护，重点服务于[[多模态多目标优化]]里对 global PS 和 local PS 的同时保留。

## 关键点

- 标准拥挤距离主要用于估计个体在局部区域的稀疏性，常作为非支配排序后的多样性选择准则。
- 本知识库中的特殊拥挤距离特指 NFCD：将[[决策空间]]和[[目标空间]]的邻域拥挤信息融合起来，以更适合 [[多模态多目标优化|MMOP]]s 的解集结构。
- 它在 ACEA-NFCD 中主要服务于 DArc 的多样性维护与截断，帮助保留不同 [[Pareto最优解集|Pareto optimal solution set]]。
- 与只看全局距离或只看单一空间的做法相比，NFCD 更强调“邻域”层面的竞争关系，能减少对孤立解的盲目保留。
- 论文消融结果表明，引入邻域与模糊融合后的 NFCD 比简单欧氏距离、[[MMODE_CSCD|CSCD]] 以及去掉邻域机制的版本更有效。

## 外部背景

- 拥挤距离最早常见于 [[NSGA-II]] 一类算法中，用于在同一 Pareto 层内优先保留分布更稀疏的个体；待核对经典来源。
- 在复杂多峰或多模态问题中，单纯的[[目标空间]]拥挤距离往往不足以区分不同决策解，因此常见改造会加入邻域或[[决策空间]]信息；待核对经典来源。
- 模糊集合可用于把多个稀疏度指标映射为一个综合评价值，从而避免硬阈值切换带来的不稳定性；待核对经典来源。
- 与 crowding distance 类似的多样性保持指标还包括 nearest-neighbor distance、fitness sharing 和 clustering-based diversity measures；待核对经典来源。
