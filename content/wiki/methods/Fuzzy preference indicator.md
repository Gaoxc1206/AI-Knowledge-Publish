# Fuzzy preference indicator

## 标准定义

Fuzzy preference indicator 通常指一种把候选解的偏好程度进行模糊化表达的指标：通过隶属度函数、模糊规则或加权融合，把多个评价维度压缩为连续的偏好分值，用于排序、筛选、档案维护或选择机制。在 [[多目标优化]] 中，它常被用来表达“更偏好哪个解”而不是只做硬性的优劣判定；与单纯的 [[拥挤距离]] 相比，它更适合处理不确定性、软约束和渐进式偏好。

## 关键点

- 标准上，Fuzzy preference indicator 属于把多维评价映射为单一偏好值的模糊化工具，强调连续偏好而非硬阈值判断。
- 在这篇 [[多模态多目标优化]] 论文的相关机制中，模糊思想被用于将[[决策空间]]与 [[目标空间]] 的邻域拥挤信息融合，以支持选择与截断；但术语本身未被单独展开。
- 这类指标通常服务于保留“更值得继续搜索”的个体，尤其适合需要同时兼顾收敛与多样性的场景。
- 相较于只依赖几何距离或单一空间度量，模糊偏好指标更能表达局部竞争关系和稀疏程度。
- 在包含多个 Pareto 解集的任务里，模糊偏好可作为排序或偏好引导的一部分，帮助稳定保留潜在优质解。

## 别名

- FPI
- fuzzy preference measure
- fuzzy preference index

## 外部背景

- 模糊偏好指标常见于多准则决策，把“更好/更差”的关系转成 0 到 1 的连续偏好程度。
- 常见实现包括三角形、梯形或 S 型隶属度函数，以及基于规则的模糊推理。
- 在[[Evolutionary Algorithm|进化算法]]中，模糊机制常用于环境选择、档案维护和多样性评估，以缓解噪声和边界模糊问题。
