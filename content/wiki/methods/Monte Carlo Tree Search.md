# Monte Carlo Tree Search

## 定义

[[Monte Carlo estimation|Monte Carlo]] Tree Search（MCTS）在给定上下文中被作为[[分子优化]]领域中的一种已有方法提及，尤其可用于[[黑盒优化]]场景。相关笔记将其与基于[[分子图]]的[[遗传算法]]等方法并列，说明它可作为离散化[[化学空间]]中的搜索策略之一。至于其具体搜索流程、选择/扩展/模拟/回传细节，当前上下文未提供，待从更多论文中补充。

- 它与基于分子图的遗传算法等方法并列出现，说明其适用于离散分子搜索问题。
