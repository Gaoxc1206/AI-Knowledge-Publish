# 强化学习分子生成

## 标准定义

强化学习[[分子生成]]是将分子生成过程建模为序列决策问题的方法：模型在每一步根据当前状态选择动作，逐步构造 [[SMILES]]、图结构或其编辑操作，并通过奖励函数[[可控生成|引导生成]]结果朝目标性质优化。常见做法包括策略梯度、Q-learning、actor-critic 或基于奖励重加权的采样；奖励通常由可合成性、相似性、活性、毒性、[[QED]]、logP 等指标组合而成。它特别适用于黑盒目标和离散搜索空间中的[[分子生成|分子设计]]。

## 在本知识库中的用法

在给定论文中，强化学习分子生成主要作为相关工作和对比基线出现，代表方法包括 [[REINVENT]]。论文关注的是用[[大语言模型]]进行[[分子性质预测]]与[[可控生成|条件生成]]，并在 [[黑箱优化|黑盒优化]] 式的[[分子优化]]流程中结合群体搜索、[[拒绝采样]]思想和动态 fine-tuning；因此这里的强化学习不是本文主方法，而是用于说明先前分子优化范式的参考对象。论文结果中，RL 基线在 PMO benchmark 上整体弱于本文的 LLM 方法。

## 关键点

- 核心思想是把分子生成视为逐步决策过程，并用奖励函数直接优化目标性质，而不是只做无条件采样。
- 常与 [[SMILES]] 生成、分子编辑、策略搜索结合，适合离散且组合爆炸的化学空间。
- 在本知识库对应论文中，RL 分子生成更像是 baseline；本文主方法是 LLM + 群体式优化 + 动态 fine-tuning。
- 论文对比中，REINVENT 等 RL 方法在 PMO benchmark 上落后于 Chemlactica/Chemma 系列模型。
- RL 方法通常依赖奖励设计，若奖励稀疏或噪声大，容易出现训练不稳定或模式坍塌。

## 外部背景

- 经典分子强化学习通常采用 policy gradient 或经验回放来提高高奖励分子的生成概率，待核对经典来源。
- REINVENT 常被视为分子生成中较早且有代表性的强化学习框架之一，待核对经典来源。
- 强化学习分子生成常用于单目标活性优化、性质约束优化和多目标优化，待核对经典来源。
- 与 [[GFlowNet|GFlowNets]] 相比，RL 更强调沿单一路径最大化累计奖励；与遗传算法相比，RL 更偏向学习式搜索，待核对经典来源。
