# external TADF dataset

## 标准定义

external TADF dataset 通常指与热激活延迟荧光（TADF, thermally activated delayed fluorescence）分子相关的独立数据集，收录 TADF 分子的结构及其部分光物理或电子性质，用于模型的外部验证、分布外测试、迁移学习或重构能力评估。若数据集的具体标注、采集标准和规模不同，其用途也可能从[[分子性质预测|性质预测]]扩展到生成模型评估。

## 在本知识库中的用法

在本文中，external TADF dataset 主要被用作图自编码器的外部重构测试集，用来检验[[潜在空间]]对新骨架的泛化能力。论文报告该数据集上的重构成功率为 77.8%，低于 [[FluoDB]] 的 in-distribution test set 上的 94.0%，说明面对分布外的 TADF 骨架时重构难度更高，但仍能保持较好的结构有效性和相似性。

## 关键点

- 它在本文里是一个外部测试数据集，而不是主要训练集，核心用途是评估分布外泛化。
- 本文用它来衡量 graph-to-sequence autoencoder 的重构成功率，反映潜在表示对新荧光骨架的适应能力。
- 77.8% 的重构成功率表明模型在 TADF 类分子上仍有较强可用性，但性能明显低于分布内测试。
- 从研究语境看，它更偏向于验证生成/重构模型的稳定性，而不是单独用于性质回归。
- 具体数据规模、字段组成和筛选标准：待从更多论文中补充。
